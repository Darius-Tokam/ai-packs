# Kit de reprise d'un projet avec l'IA

Un dossier portable pour conserver les décisions et reprendre le travail dans une nouvelle conversation. Pour une application, une offre ou un lancement.

## Les fichiers du kit

- [Prompt pour préparer la reprise](01-preparer-la-reprise.md)
- [Modèle de dossier à remplir](REPRISE-PROJET.md)
- [Prompt pour reprendre dans une nouvelle conversation](02-reprendre.md)
- [Exemples entrepreneur et développeur](EXEMPLES.md)

## Utilisation

1. Dans la conversation actuelle, colle le prompt de `01-preparer-la-reprise.md`, suivi du modèle `REPRISE-PROJET.md`.
2. Relis le résultat : corrige les décisions, vérifie ce qui est réellement terminé et retire toute information confidentielle. Enregistre le dossier daté de ton côté.
3. Dans une nouvelle conversation, colle le prompt de `02-reprendre.md` et le dossier rempli. Joins uniquement les documents utiles que tu peux partager.
4. Valide la prochaine action proposée. Actualise le dossier à chaque arrêt important.

Le modèle est du texte Markdown, utilisable dans un éditeur de texte ou une conversation acceptant du texte. Aucune intégration, mémoire automatique ou abonnement à un service particulier n'est fourni. Les conditions d'accès de ton outil IA restent applicables.

## Limites

Une IA ne peut résumer que les informations auxquelles elle a accès. Le dossier ne récupère pas un historique perdu, ne donne pas accès aux fichiers mentionnés et ne garantit pas qu'une IA suivra chaque consigne. Un lien ne remplace pas son contenu. Vérifie les faits et joins les sources nécessaires.

Aucun gain de temps chiffré ni résultat d'essai avec un modèle d'IA n'est revendiqué. Les exemples sont fictifs. Il ne s'agit pas d'un workflow n8n ou d'un système d'agents autonome.
