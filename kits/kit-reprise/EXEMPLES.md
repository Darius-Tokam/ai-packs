# Exemples fictifs d'usage

## Entrepreneur : préparer une offre

Objectif : tester une offre d'accompagnement à l'organisation auprès de petites équipes.
Décision confirmée : proposer un entretien individuel avant de construire une formation.
Piste écartée : réaliser tout le contenu avant de parler aux personnes visées.
Terminé : une première description de l'offre, à joindre à la nouvelle conversation.
À confirmer : les objections et le prix acceptable, aucun entretien réalisé dans cet exemple.
Prochaine action : préparer les questions d'entretien à partir de l'offre jointe.

## Développeur : reprendre une application

Objectif : permettre de créer et consulter des tâches dans une application locale.
Décision confirmée : stockage local pour ce prototype.
Piste écartée : ajouter l'inscription avant de valider le parcours principal.
Terminé : écran de création présent dans le dossier du projet, vérification à refaire car aucune preuve n'est jointe à cet exemple.
À confirmer : comportement quand le titre est vide.
Prochaine action : fournir le composant et vérifier le comportement de validation.

Ces exemples décrivent des situations inventées ; ils ne sont pas des résultats d'essais.
